Garis Senja is a round-based tactical FPS in the browser: two teams of bots, short rounds won by elimination or by planting and defusing a bomb, money between rounds to buy weapons and grenades, and gunfire where stopping to aim pays. Single-player against bots, on an original dusk harbor map, built on three.js with no build step and no network requests. All art is procedural geometry and all sound is synthesized in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
